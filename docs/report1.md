# Отчет по лабораторной работе: Практики 1.1–1.3

## Тема проекта

Бэкэнд для телеграм-приложения по бронированию услуг у мастеров (стрижки, маникюр, брови и пр.).

## Стек технологий

FastAPI — асинхронный web-фреймворк

SQLModel + PostgreSQL — работа с БД

Alembic — миграции

uvicorn — запуск сервера

## Структура репозитория

Каждая практика оформлена отдельным файлом.

Код структурирован по бизнес-логике: models/, schemas/, routers/, services/, core/, migrations/.

Реализованный функционал:

- Практики 1.1–1.3
- Проект инициализирован и структурирован.
- Созданы таблицы через ORM с учетом связей one-to-many и many-to-many.
- Реализованы CRUD-операции.
- Настроены миграции с Alembic.
- Прописаны аннотации типов во всех API-методах.
- Организована файловая структура проекта.
- Добавлены комментарии к сложным частям кода.

- Регистрация и авторизация пользователей через Telegram Token.
- Проверка токена на каждом защищенном маршруте.
- Хэширование паролей

## Примечание

Проект является полностью асинхронным, включая работу с БД
